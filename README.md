# BookTracker

Шкурган Михаил Андреевич

## Описание программы

Графическое приложение для учёта прочитанных книг. Позволяет:
* добавлять книги с указанием названия, автора, жанра и количества страниц;
* фильтровать книги по жанру и количеству страниц;
* сохранять данные в формате JSON;
* загружать сохранённые данные при запуске.

## Требования к запуску

* Python;
* библиотека `tkinter` (встроена в Python).

## Примеры использования
В первом поле программы пишите название книги, Например:
Андрей соколов
В следующем поле пишите автора вашей книги.
В следующем поле напишите жанр вашей книги, например фантастика.
В следующем – кол-во страниц
После нажатия на кнопку Добавить книгу, она у вас сохранится в нижнем поле со всеми данными
Так же здесь реализована система фильтрации: вы можете фильтровать по жанру и по кол-ву страниц. Чтобы очистить фильтр нужно нажать соответствующую кнопку
